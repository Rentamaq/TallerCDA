# Taller Rentamaq CDA · Estado de equipos

Panel web que registra lo informado en el grupo de WhatsApp «Taller Rentamaq CDA».

- `index.html` – panel con 3 pestañas: F/S y revisiones (con horas fuera de servicio en tiempo real), Operativos, Dashboard.
- `data.js` – registros leídos del grupo. Es el único archivo que se actualiza en cada lectura.

Los ingresos manuales y las ediciones de patente / N° Teck se guardan en el navegador de quien los hace.
Para compartirlos: botón «Descargar data.js» y reemplazar `data.js` en este repositorio.
